# KOIB‑4.3 — RAG‑система для технической документации КОИБ

Система Retrieval-Augmented Generation на русском языке для автоматизированного консультирования операторов комплексов обработки избирательных бюллетеней (КОИБ). Использует официальную техническую документацию по разным моделям КОИБ.

## Ключевые возможности

✅ **Гибридный поиск**: векторный (FAISS) + BM25 + переранжирование  
✅ **Фильтрация по модели КОИБ**: точный поиск по конкретной модели устройства  
✅ **Валидация ответов**: проверка ссылок на источники, детекция галлюцинаций  
✅ **Безопасность**: блокировка неопределённых ответов, детекция чувствительных тем  
✅ **Аудит**: JSONL-логирование всех запросов с метаданными валидации  
✅ **Карантин чанков**: изоляция проблемных фрагментов документов  

## Быстрый старт

```bash
# 1. Установка зависимостей
pip install -r requirements.txt

# 2. Индексация документов (PDF/DOCX из data/docs/)
python main.py --ingest

# 3. Запрос
python main.py --query "Как включить КОИБ-2010?"

# 4. Интерактивный режим
python main.py --interactive
```

## Основные команды

| Команда | Описание |
|---------|----------|
| `--ingest` | Индексация документов из `data/docs/` |
| `--query "текст"` | Единичный запрос к системе |
| `--interactive` | Интерактивный режим диалога |
| `--eval` | Оценка качества по тестовому набору |
| `--add-file <путь>` | Добавить один файл без перестройки индекса |
| `--model <тип>` | Фильтр по модели КОИБ (koib2010, koib2017a, и т.д.) |

## Архитектура пайплана запроса

```
Вопрос пользователя
       │
       ▼
1. Детекция чувствительных тем (safety.py)
       │
       ▼
2. Поиск чанков (retrieval.py)
   • Фильтрация по model_type (если указана)
   • Исключение чанков из карантина
       │
       ▼
3. Генерация ответа (generation.py)
   • Формирование промпта с контекстом
   • Цитирование источников [Документ: X, стр. Y]
       │
       ▼
4. Валидация ответа (validation.py)
   • Проверка наличия ссылок на источники
   • Блокировка маркеров неопределённости («возможно», «вероятно»)
   • Семантическая проверка согласованности (cosine ≥ 0.75)
       │
       ▼
5. Логирование (logging_module.py)
   • Запись в JSONL: timestamp, query_hash, ответ, статус (approved/review/rejected)
       │
       ▼
Финальный ответ пользователю
```

## Статусы ответов

| Статус | Критерии |
|--------|----------|
| `approved` | Все проверки пройдены |
| `review` | Нет ссылки на источник ИЛИ чувствительная тема ИЛИ низкая семантическая согласованность |
| `rejected` | Обнаружены маркеры неопределённости |
